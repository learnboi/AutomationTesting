# CarePoint

Healthcare practice site with fictional doctors, specialty/fee/rating filters, profile details, appointment slot selection, synthetic patient validation, confirmation, and appointment history. No real health data is requested. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/carepoint`; map `care.trytestme.online` after DNS verification.
