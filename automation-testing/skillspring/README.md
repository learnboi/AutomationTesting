# SkillSpring

Education practice site with course search/filter/sort, details, local enrolment, learner records, lesson/quiz interaction, required-answer validation, scoring, and retake-ready state. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/skillspring`; map `learn.trytestme.online` after DNS verification.
