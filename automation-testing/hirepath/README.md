# HirePath

Recruitment practice site with fictional jobs, title/company/location search, salary and category metadata, application validation, resume file type/size checks, expired listings, duplicate email behavior, confirmation, and history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/hirepath`; map `jobs.trytestme.online` after DNS verification.
