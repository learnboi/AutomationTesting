# ConnectPlus

Telecom practice site with fictional plan catalogue, search/filter/sort, plan details, comparison-ready data, synthetic postal-code serviceability, new/upgrade/downgrade request forms, duplicate request validation, confirmation, and history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/connectplus`; map `connect.trytestme.online` after DNS verification.
