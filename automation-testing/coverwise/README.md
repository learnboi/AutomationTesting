# CoverWise

Insurance practice site with fictional health/vehicle/life plans, search/filter/sort, coverage comparison data, age and cover validation, sample quote submission, required document notes, and local history. All records are demonstrations only. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/coverwise`; map `cover.trytestme.online` after DNS verification.
