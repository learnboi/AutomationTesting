# TripNest

Travel practice site with fictional hotel/stay search, destination and type filters, price/rating sorting, date and traveller validation, booking confirmation, sold-out inventory, and history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/tripnest`; map `travel.trytestme.online` after DNS verification.
