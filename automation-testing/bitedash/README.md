# BiteDash

Food delivery practice site with fictional restaurant/cuisine discovery, ratings and delivery fees, menu details, local cart/checkout, coupon/address/phone validation, unavailable restaurant data, simulated order confirmation, and history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/bitedash`; map `food.trytestme.online` after DNS verification.
