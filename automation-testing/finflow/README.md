# FinFlow

Personal finance simulation with fictional balances, transaction search/filter/sort, transaction detail cards, simulated beneficiary transfer, amount validation, duplicate references, and history. No real financial operation is possible. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/finflow`; map `money.trytestme.online` after DNS verification.
