# ShopTest

E-commerce practice site with product search, category filtering, price/rating sorting, detail pages, local cart state, out-of-stock data, coupon-ready checkout validation, guest shipping selection, confirmation, and order history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy from this folder with the Vercel project root set to `automation-testing/shoptest`; map `shop.trytestme.online` after DNS verification.
