# HomeScout

Real-estate practice site with fictional property search, location/type/budget/bedroom metadata, price sorting, detail pages, favourites-ready cards, enquiry/viewing forms, invalid contact states, and history. Test-only login: `demo` / `test123`.

Run `npm install`, `npm run dev`, `npm run build`, and `npm test`. Deploy with root `automation-testing/homescout`; map `homes.trytestme.online` after DNS verification.
