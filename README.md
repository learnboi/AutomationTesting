# MediCare Plus

MediCare Plus is a responsive fictional healthcare and hospital-management platform built with React, TypeScript, React Router, Tailwind CSS, and localStorage persistence.

## Run locally

```bash
npm install
npm run dev -- --port 5180
```

Production verification:

```bash
npm run build
```

## Included workflows

- Public healthcare pages, doctor discovery, specialties, packages, FAQs, contact, privacy, and terms
- Patient registration, login, protected dashboard, appointments, records, prescriptions, invoices, diagnostics, profile, and notifications
- Doctor portal with assigned appointments and consultation summaries
- Administrator portal with dashboard statistics and local management views
- Local-only simulated payments and browser persistence through localStorage

All data is fictional and stored locally for this application. No external healthcare, messaging, payment, or identity-verification integrations are used.
